# An individual-based model of Sacramento River green sturgeon

Development of an individual-based model of Sacramento River green sturgeon.
Initial focus is on a state-transition model of movements during spawning migrations.

Files:
gs_spawning_ibm_nocovar.R: Implements a simple stochastic state-transition model without effects of environmental covariates (flow, temperature) on behavior. Primarily used for developing and testing the model framework.
